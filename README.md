# keiba-board

中央競馬（JRA）の全レースを自動で記録・予想する。

**ボード → https://oookuboy.github.io/keiba-board/**

予想は GitHub Actions が自動で作る。人が操作するところは無い。

| いつ | 何が起きるか |
|---|---|
| 木 20:00 | JRA公式から出馬表を取り、暫定予想（印だけ・買い目なし） |
| 金 21:00 | 枠順確定後に取り直す |
| 土日 05:00 / 07:00 | 本予想。オッズを見て ◎○△× と買い目を確定 |
| 日月 09:00 | 前日の着順と払戻を照合し、成績と実戦ログを更新 |

## 設計の要点

- **狙いは穴・大穴。** 堅く収まると判断したレースは1点も買わない
- **能力評価にオッズを一切使わない。** 人気を見るのは自信度の判定と配分だけで、
  そこは型（`market_` 接頭辞）とテストで機械的に隔離してある
- **数字は測ってから載せる。** 回収率は分散が大きく、数百レースでは優劣が出ない。
  1日の結果で重みを動かさない

詳細は [keiba/README.md](keiba/README.md)。実測値・失敗した試み・その理由まで
そこに書いてある。

## 注意

競馬は不確実性を伴う賭博であり、このシステムは的中を保証しない。
バックテストの回収率が100%を超えても将来の収益を意味しない。
