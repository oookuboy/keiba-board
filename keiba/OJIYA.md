# おじや予想（ボード別枠）

ボード（index.html）の下部に表示される、自動予想とは別枠の手動予想。
ユーザーの個人アシスタント「おじや」が、中央競馬の重賞・メインレースを中心に出す。
ユーザーが「おじやの予想をここに乗せて」と言って始まったもの（2026-11-02）。

## 仕組み

- データは `keiba/data/ojiya.json` のみ。自動予想のパイプライン（collect / predict /
  review）はこのファイルを読まないし、書かない。逆も同じで、おじやは
  `keiba/data/YYYY-MM-DD.json` や `index.json` を書き換えない。
- index.html は日付ごとに ojiya.json を引き、一致する日があれば
  「おじや予想（自動予想とは別枠）」として描く。無ければ何も出ない。
- 投稿はおじやが GitHub 経由で ojiya.json を更新して行う（main へ直接）。

## 形式

```json
{
  "days": [
    {
      "date": "2026-11-08",
      "note": "その日の補足（任意）",
      "races": [
        {
          "venue": "東京",
          "race_no": 11,
          "name": "アルゼンチン共和国杯",
          "grade": "G2",
          "marks": [
            {"mark": "◎", "umaban": 5, "name": "馬名"},
            {"mark": "○", "umaban": 3, "name": "馬名"},
            {"mark": "▲", "umaban": 9, "name": "馬名"},
            {"mark": "△", "umaban": 12, "name": "馬名"}
          ],
          "comment": "根拠は馬の実績（コース・距離・回り・馬場・位置取り・休み明け）で書く",
          "bets": "買い目（任意）",
          "result": "結果のひと言（任意。回顧後に追記）"
        }
      ]
    }
  ]
}
```

## 守ること

- 有料データ（調教タイム・厩舎コメント本文）は書かない。自動予想側の公開ルールと
  同じ扱いにする。
- 的中を保証する書き方はしない。
